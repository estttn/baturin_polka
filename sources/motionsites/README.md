# Motionsites — библиотека образов

Вы называете карточку с доски. Агент берёт промпт и картинку и собирает сайт **по этому каркасу**, без чужого бренда.

Это не 600 папок в `etalons/`. Эталоны Бюро остаются отобранными. Здесь — каталог с [motionsites.ai](https://motionsites.ai/): стоп-кадр на каждую карточку, без чужой анимации.

## Как пользоваться

1. Откройте `review.html` (если сервер запущен: http://127.0.0.1:8765/review.html).
2. Найдите стиль. Напишите в чат точное название, например: `Velorix IIC`, `Apex SaaS`.
3. Агент ищет в `library.json`, читает промпт из `_upstream/prompts/`, смотрит превью.

## Что лежит на диске

| Файл | Зачем |
|---|---|
| `review.html` | Витрина: 469 карточек, у всех картинка |
| `library.json` | Поиск по имени → промпт + картинка + live URL |
| `official_catalog.json` | Публичные поля каталога Motionsites (id, title, URL превью) |
| `_upstream/prompts/` | Исходные спеки с GitHub (470 md, в git) |
| `posters/` | Старые GIF (~460 MB), локально; превью в review — CDN Motionsites |
| `stills/` | JPEG с публичных mp4, где не было постера (в git) |

Картинки взяты с motionsites.ai: постер PNG, webp с сетки, кадр из их превью. Не генерировать фейковые мокапы нейросетью.

Промпт локально есть у **330** из **469**. Остальные заберём с GitHub по имени, когда скажете.

Пересобрать витрину: `python fetch_official_stills.py` затем `python build_review.py` и `python build_index.py`.

## Правило

Копировать раскладку, тип, свет, CTA. Не копировать название бренда, оффер и чужие кейсы.
