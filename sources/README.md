# Карьер

Сырьё для поиска паттернов. **Не эталоны.**

Эталон живёт в `etalons/`: класс, `USAGE.md`, один канон. Карьер живёт здесь: ссылки на чужие библиотеки, кластеры, что уже снято на полку.

Правило: 661 почти одинаковых тёмных hero не делают работу лучше. Делает лучше **закрытый класс** — один представитель на сигнатуру.

Перед дизайном: `TAXONOMY.md` → `etalons/index.yaml`. Если класса нет — `sources/*/clusters.yaml`, взять 1–2 представителя, проверить Anti-Slop, положить победителя в `etalons/`.

Смотреть глазами: `sources/motionsites/review.html`. Название с доски → агент берёт промпт из библиотеки и собирает по этому образу.
