# agency-light-shader

Канон — папка `site/`: сайт, который собран и дописан (услуги, клиенты, FAQ, подвал). Не первый черновой промпт из трёх блоков.

## Что это

Светлый лендинг студии. Сетка `max-w-[1440px]`, системный шрифт, акцент `#F26522`, фон `#EFEFEF` / белый / `#F5F5F5`.

Секции по порядку: Hero → About → Cases → Services → Clients → FAQ → Footer.

Hero: шейдер `shaders/react` — `Swirl` + `ChromaFlow` (зелёный след сверху–вниз) + `GlassTiles` (блоки, не флейты) + `FilmGrain`. Нав — белая таблетка. CTA — text-roll и стрелка −45°.

Услуги — строки с сроком, не три карточки с иконками. Клиенты — набор и NDA-имена текстом, не лента логотипов. FAQ — конкретные ответы студии, не «How do I get started». Подвал закрывает `#connect`.

## Брать

- Ритм: numbered badge + pill + крупный h2
- Hover: text-roll, расширяющаяся круглая кнопка на кейсе
- Чередование белый / `#F5F5F5` / `#EFEFEF`
- Честные заглушки вместо фейковых логотипов и метрик

## Не брать

- Имя Axion, копирайт, оранжевый как «бренд Бюро»
- Картинки и видео по URL как свои кейсы
- Дорисовку logos / testimonials «чтобы было как у всех» сверх этого каркаса

## Запуск канона

```bash
cd site
npm install
npm run dev
```
